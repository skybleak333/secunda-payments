# Проверка решения

Проверено 22 октября 2026 года. Python 3.12, PostgreSQL 17,
RabbitMQ 4.1, FastStream 0.6.7. Зависимости зафиксированы в requirements-файлах.

| Проверка | Результат |
| --- | --- |
| pytest, реальные временные схемы PostgreSQL | 25 passed |
| Ruff lint и форматирование | пройдены |
| Alembic upgrade head и сравнение миграции с моделями | пройдены, расхождений нет |
| Docker build, запуск API и consumer после миграций | пройдены |
| Создание/чтение и повтор запроса с Idempotency-Key | пройдены |
| Повтор RabbitMQ-сообщения после завершения платежа | дополнительный webhook не отправлен |
| HTTP 503 от приёмника | 3 попытки, затем сообщение в RabbitMQ DLQ |
| Невалидное сообщение RabbitMQ | отклонено, получено в DLQ через DLX |
| Остановленный RabbitMQ | API вернул 202, платёж оставался pending |
| Возврат RabbitMQ после сбоя | платёж обработан, webhook доставлен |

Примеры и ограничения гарантий доставки описаны в README.
Тестовый шлюз эмулирует платёж: настоящие деньги и внешние платёжные системы
в проверках не используются.
